# 第一阶段中期报告：smoke 与三种子 pilot（精度修正版）

## 1. 范围与结论

本报告只解释已完成的 smoke/pilot。全文数值来自统一确定性FP32后重算的当前结果；原预测、表和报告已保存在 `results/logs/precision_before_fix.zip`，不与当前数据混用。完整数据、第二架构、NSTDB和九电极结果见最终报告。

**Pilot证据有限，不能声称普遍性评价偏差。** 0dB电极映射比逐导联RMS匹配独立噪声有更高的患者等权损失；但20/10/0dB的Macro-AUROC配对训练种子95%CI均包含零。10/20dB效应方向并非所有训练种子一致，追加噪声重复也显示方向不稳定。

研究对象是标准导联关系诱导的结构化扰动，不是恢复PTB-XL真实电极电势，也不是脱落、饱和或右腿驱动电路模型。Clean表示未额外加噪，不保证原始记录无采集伪差。

## 2. 数据、模型和执行

- PTB-XL1.0.3，100Hz、10秒、12导联；完整元数据21799条/18869名患者。
- Smoke候选为官方元数据前1000条中的988条有效记录/925名患者；按官方fold固定选256/100/100，训练seed17、1epoch。测试100条来自91名患者。
- Pilot候选为前10000条：135条无diagnostic superclass被排除，保留9865条/8817名患者；候选train/val/test为7685/1074/1106。用subset_seed2026在各官方分区内选4000/1000/1000；测试1000条/896名患者。
- 该候选前缀不是全库均匀抽样，不应把pilot当作full。官方fold1–8训练、9验证、10测试，患者不跨fold。标签按官方SCP诊断代码键构建，likelihood0表示未知，不当作阴性；无目标标签记录显式排除。
- 每记录每导联只去时间均值，保留mV；训练子集拟合单一全局RMS标量。加噪发生在mV空间，再使用同一标量。没有输入加噪训练、逐导联标准化或滤波。
- ResNet18风格1D模型，2/2/2/2 blocks、base_channels24、BatchNorm、545717参数；AdamW、lr0.001、weight_decay0.0001、batch128、15epochs，训练seed17/29/43。仅按干净验证Macro-AUROC选checkpoint，五类F1阈值仅由验证集选择。
- 本机RTX4070 Laptop CUDA。DGX Sync域名解析失败、历史IPv6超时；未使用远程资源。训练/验证/评估均禁用TF32并启用确定性算法。

实际命令（项目根目录，PYTHON指向项目虚拟环境）：

```sh
python -m src.prepare_ptbxl --limit 1000 --require-all --output-dir data/processed_smoke --results-dir results/smoke_preparation
bash scripts/run_smoke_test.sh
python -m src.prepare_ptbxl --limit 10000 --require-all --output-dir data/processed_pilot --results-dir results/pilot_preparation
bash scripts/run_pilot.sh
python -u scripts/replay_noise.py --config configs/phase1_pilot.yaml --noise-seeds 101 202 303 404 505
```

精度修正后的脚本重跑复用已完成checkpoint，不重新训练、不重调阈值；已有缓存不得无故重新prepare，否则数据身份会改变。

## 3. 映射与控制

`src/lead_matrix.py`给出12×9矩阵。节点顺序RA/LA/LL/V1–V6，导联顺序I/II/III/aVR/aVL/aVF/V1–V6；胸前导联为V−(RA+LA+LL)/3，因此使用**−1/3**，而非Guidance示例数组中与公式矛盾的+1/3。矩阵rank8，共模抵消；Einthoven、增强肢体关系、WCT、单位电极传播和零RL列通过检查。

审阅补充已完成**追溯矩阵版本核验**：当前smoke的12组、pilot的27组、pilot噪声重复的135组矩阵依赖预测全部逐记录重建并前向重放，概率最大差为0，标签/ID/索引/阈值/噪声强度/种子逐数组一致；连同full及其重放共822组通过。矩阵规范SHA256为 `4f852acd9c5a4f7b35a207f5078d70f842de3077d648716950a66502951bfe9d`。旧产物没有生成时矩阵哈希，不向旧配置/缓存/checkpoint补写；噪声示例内A、重建结果及图表来源见 `results/tables/review_supplement/matrix_artifact_evidence.json`、`matrix_replay_files.csv`。三次主运行的矩阵图和单位传播图分别字节相同，图中胸前肢体系数均为−0.33（−1/3的显示精度）。历史TF32归档仍排除。

新增患者级**AUROC** bootstrap和严格边际实验针对full队列，见最终报告；不把full区间套用到本pilot。本报告下列AUROC区间仍明确是三训练种子区间，既有pilot负结果未改写。

合成噪声为0.5–40Hz矩形FFT带限Gaussian。independent只匹配全局SNR；electrode先生成9节点再经A映射、全局缩放；independent_rms只调整独立导联噪声，使其逐导联RMS匹配映射结果，不改动映射条件；covariance使用新导联空间样本、经验白化和目标经验协方差着色，ddof0、无jitter、只截断舍入级特征值。两条件共享经验协方差，不据此宣称所有类型的高阶/时间分布相同。

128条固定验证ECG上的非对角绝对相关均值：independent0.02856，electrode0.19736。相对映射条件的聚合Welch PSD L1差：independent2.27%、independent_rms2.31%、covariance2.80%。这不是逐记录逐频点PSD完全一致。当前1000条测试实例的SNR最大误差1.67e−7dB，匹配RMS相对误差最大1.18e−8；全量逐文件重算证据见 `results/logs/final_verification.json`。

主噪声由base8128、ecg_id和kind确定，独立于训练种子；同一0dB波形缩放至10/20dB。保存预测、标签、患者ID、阈值、索引、实际SNR、12导联RMS/SNR及replay_seed。

## 5. 验证、失败与修正

- Smoke五阶段均exit0，16组原始模型指标有限，真实反向传播、checkpoint和日志已保存。当前100条clean预测重算最大差0；重建一条10dB映射预测最大差4.47e−8。
- 数据、矩阵、噪声和缺少整个配置SNR组的回归检查见 `tests/`、`results/logs/tests.xml`；Windows临时mmap释放问题已修复。
- statistics现在要求完成的评估协议和完整配置网格；evaluate拒绝未完成checkpoint、模型/种子不符或当前数据身份不符。实际拒绝场景见 `integrity_guard_smoke.json`。
- 数值复核发现早期独立评估启用cuDNN TF32，而训练/验证禁用；现复用同一执行策略。重算前后235份预测的标签、ID、阈值、索引、噪声强度和种子逐数组完全相同，仅模型数值结果改变。Pilot39组中195000个二元判定有38个变化，最大概率差0.002427；原版完整归档，当前表已全部刷新。见 `results/logs/precision_correction.json`。
- NSTDB成功下载和解析，并非最终回退缺失。先期诊断显示短片段经验相关和PSD差异较大；其模型扩展只能解释为探索性回放，不作为纯相关结构效应。完整结果在最终报告。
